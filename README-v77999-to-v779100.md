## 変更内容

- 食材81種類に共通の解説を用意。採用済みの食性・味・香りの中から説明に役立つ要素を使い、作用を採用していない食材は料理の中での役目を説明します。
- 食材カードを「食材名 → 短い選定理由 → 料理例 → 開閉式の東洋医学解説 → 食材別の記録」に整理。条件ラベルを再掲していた「今回選んだ理由」を置き換えました。
- 飲料カードを「飲料名・記録 → 短い理由 → 飲み方・カフェイン表示 → 開閉式の東洋医学解説」に整理。カフェイン情報だけが理由の開閉欄に残る問題を解消しました。
- 飲料を既存14から22項目に拡充。通常の飲料は21、葛湯は補食として主案2杯から除外します。既存14項目のIDは保持しています。
- 追加8項目はマイカイ花茶、陳皮しょうが茶、ジャスミン花茶、菊花クコ茶、なつめ龍眼茶、しょうがなつめ茶、はとむぎ小豆茶、ルイボス＋マイカイ花。食品用の指定原料と配合を、説明・選定・カフェイン表示で対応させています。
- コーヒーの疲れに対する覚醒加点、香りだけの気滞への加点、とうもろこしの実の広い消食加点を削除。生姜の温胃と元気を補う作用も区別しました。コーヒーとルイボス自体は維持しています。
- 短い理由を実際の選定根拠から生成。飲料は同じ原料が重なる候補同士の同時提案を避け、同じ対象日では今日・明日の画面の選択をそろえます。
- 106の料理例を維持し、そのうち12例で主役以外のごはん・野菜等を明示。追加食材の寒熱の適合も確認します。
- 飲食記録の既存JSONへ、選定理由に加えて解説・内容バージョン等を保存。以前の記録にこれらがない場合も読み込めます。
- 設定画面、PWA通知案内、通知オン時の案内を、公開画面の「40点以上（いたわり以上）」へ統一。内部の0〜10点の閾値4と通知の送信判定は維持しています。既存の個別閾値がある場合は、その値を0〜100点へ換算して表示します。
