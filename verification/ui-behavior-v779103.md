# v7.79.103 UI・操作検証

検証日: 2026-10-26

## 方法

実際のNext.jsプロダクションビルドをローカルで起動し、Chromium 153.0.8010.0で確認。認証セッション、予報、利用権限、案内の保存APIをテスト用に模擬し、外部ネットワークへの送信は遮断しています。サーバー・DB・決済・実メールには接続していません。

表示確認にはアプリと同じZen Kaku Gothic Newの400/500/700/900を使用。ビルド環境のフォント取得スタブに対応するため、ローカルQA時だけ同書体のフォントを読み込みました。アプリの書体設定・依存パッケージは変更していません。

## 確認項目

- 幅320/390/820pxでチェック前ログインを表示。既存6タイプの画像を確認。
- チェック前に「無料登録」「14日」「支払い情報」「自動課金」「580円」が表示されない。
- Google/メールのログインボタン、展開式メール入力、既存の戻る操作。
- 幅390×844px、320×568pxで体験ポップアップを確認。
- 予報取得が完了するまで案内を出さず、正常表示後に優先表示。
- 終了日時、月額580円、自動課金なしを確認。
- 大きい×、下部ボタン、背景タップ、Escapeで閉じる。
- 初期フォーカスは×。Tab/Shift+Tabがポップアップ内を循環する。
- 閉じると背景スクロールが復帰。
- 再読み込み後に同じアカウントへ再表示しない。
- 同じアカウントを別ブラウザコンテキストで開いても、保存済みなら再表示しない。
- 別アカウントには独立して案内する。
- 有料契約者・体験終了者・予報エラー時には案内を出さない。
- 既存の使い方案内との同時表示を抑える。

画面確認のスクリーンショットはテスト用の一時領域にのみ保存し、フルソースへ同梱していません。
