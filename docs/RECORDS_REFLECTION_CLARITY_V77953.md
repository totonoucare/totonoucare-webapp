# v7.79.53 振り返りの見立てと確認内容を接続

## 背景

AI分析は次の項目を返していた。

- `headline`: 見立ての結論
- `observed`: 記録で確認できたこと
- `hypotheses`: 記録から考えられること
- `evidence`: 見立てに使った短い記録要約
- `next_step`: 次に試すこと

v7.79.51の画面整理では`headline`が表示から抜け、詳細欄に説明項目だけが残っていた。このため「詳しい根拠」が何を説明しているのか、画面内で対応を読み取れなかった。

## 新しい表示順

1. この期間の手がかり
2. 予報・先回りケア・実感のつながり
3. ミモルの見立て
4. 次に一つだけ
5. 予報・実感・ケアを同じ日で見る簡易グラフ
6. ミモルの見立てを詳しく見る
   - 対象となる見立ての結論
   - 記録で確認できたこと
   - そこから考えられること
   - 見立てに使った記録
   - 詳細グラフ

AI分析が未生成の時は、固定集計による手がかりと見方を表示する。保存済みAI分析の対象期間が古い時も、現在期間の表示には固定集計を使う。

## 表情

次の状態では、ミモルへ`signal=1`を渡していたわり表情を表示する。

- いたわり・守り予報でつらさがあった
- 先回りケアを試してもつらさがあった
- 安定予報でもつらさがあった

良い経過や手がかりの発見では、AIが返す通常・ひらめき・完了等のmoodを使用できる。
