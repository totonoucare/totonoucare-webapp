# v7.79.12 暮らすケアの広い場面・実行タイミング

## 結論

暮らすケアの役割は、引き続き次の二つだけです。

- 天気ストレスへ直接触れられる環境調整
- 不調が出やすい日に、負担を一か所へ集めにくくする身体の使い方

今回、身体操作の「場面」を個別家事から九つの基本動作へ戻しました。画面では広い場面を先に示し、その下で実際の操作を具体的に伝えます。

## 表示する九つの場面

| scene_family | 画面の場面 |
|---|---|
| `hold_carry` | 物を持つ・運ぶ時は |
| `push_pull_turn` | 物を押す・引く・回す時は |
| `reach_take` | 手を伸ばして物を取る時は |
| `bend_height` | かがむ・高さを変える時は |
| `sit_rise` | 立つ・座る・起き上がる時は |
| `walk_step` | 歩く・段差を移動する時は |
| `screen_handwork` | 手作業や画面操作が続く時は |
| `hold_posture` | 同じ姿勢で待つ・作業する時は |
| `lie_turn` | 横になる・寝返る時は |

`LIFESTYLE_SCENE_DEFINITIONS`を表示場面の正本とします。候補ごとの旧`scene`で上書きしません。

具体策は曖昧にしません。ただし、「まな板だけ」「モップだけ」の専用ケアにもせず、同じ基本動作を含む別の生活場面でも試せる書き方にします。

例:

- 旧: まな板や器を、こぶし一つぶん手前へ寄せる
- 現行: 手元で使う物を、こぶし一つぶん手前へ寄せる
- 旧: 重い扉や引き出しを、腕だけで引いている時
- 現行: 押す・引く物へ近づき、物が動く方向へ一歩ついていく

## 今日と明日の扱い

| タブ | 主提案 | 見出し |
|---|---|---|
| 今日 | 身体操作または環境調整 | 今日の一手 |
| 明日 | 身体操作 | 明日の一手 |
| 明日 | 今夜できる環境調整 | 今夜の準備 |

身体操作は、明日その場面が来た時に試すものです。そのため明日タブで一律に「今夜の一手」とは呼びません。

今日と明日の候補は、適合度を最優先します。身体・環境レーン、基本動作、具体策の最高点との差が`0.75`以内にある候補だけ日付で巡回します。明日だからという理由だけで、適合度の低い案へ強制交代しません。

## 保存済み予報との互換性

予報スナップショットの点数と天気データは固定したまま、暮らすケア表示だけを現行ルールから作り直します。

`baseCarePlan.version !== DAILY_CARE_LOGIC_VERSION`の場合、保存済み`lifestyle_plan`をbaseに使いません。また`trap`は常に空にし、旧版の次のコピーを持ち越しません。

- 予定や段取りを軽くする
- 休憩や止め時を決める
- 用事を先送りする
- 「ここまでで終わり」を決める

これにより、01:05固定の予報点数を変えずに、暮らすケアの現行契約を画面へ反映できます。
