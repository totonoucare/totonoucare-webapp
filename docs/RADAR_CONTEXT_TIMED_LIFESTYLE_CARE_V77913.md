# v7.79.13 暮らすケアの文脈・時間帯・季節統合

## 目的

暮らすケアを、天気と体質から自然に導ける二つの役割へ絞る。

- 天気ストレスへ直接触れる環境調整
- 不調が出やすい日に、負担を一か所へ集めにくくする身体の使い方

予定、休憩、止め時、ペース配分は扱わない。一般的な生活指導で候補数を埋めず、その日の条件と直接つながる一手がなければ提案を休む。

## 身体の使い方

画面の場面見出しは9分類を正本にする。

| scene_family | 画面の場面 |
|---|---|
| `hold_carry` | 物を持つ・運ぶ時は |
| `push_pull_turn` | 物を押す・引く・回す時は |
| `reach_take` | 手を伸ばして物を取る時は |
| `bend_height` | かがむ・高さを変える時は |
| `sit_rise` | 立つ・座る・起き上がる時は |
| `walk_step` | 歩く・段差を移動する時は |
| `screen_handwork` | 手作業や画面操作が続く時は |
| `hold_posture` | 同じ姿勢で待つ・作業する時は |
| `lie_turn` | 横になる・寝返る時は |

本文は抽象語だけにしない。広い場面を壊さない範囲で、理解に必要な実例を添える。

- 細い持ち手: バッグや買い物袋
- 柄の長い道具: 掃除機・モップ・フロアワイパー
- 画面の遠い位置: 親指が届きにくい画面の端

一方、身体OSの内部語である橈骨、正中、張力、起始側などは画面へ出さない。成功判定も姿勢の形ではなく、同じ動作が軽い、肩や腰へ重さが残らない、手首を固めず動ける、といったラクさの変化を使う。

## 今日と今夜〜明朝

| タブ | body候補 | environment候補 | 表示 |
|---|---|---|---|
| 今日 | 日中の8基本場面 | 日中に試せる環境調整 | 今日の一手 |
| 明日 | 寝返り、仰向けへ戻る、横向きから起きる | 寝床・翌朝を含む環境調整 | 今夜〜明朝の一手 |

寝返り・起床は今日タブへ出さない。通常の持つ、歩く、画面操作なども明日タブへ出さない。明日タブでは暮らす・食べる・ほぐすをすべて`今夜〜明朝`の時間軸で表示する。

## 環境調整

環境候補は18件。主なまとまりは次の通り。

- 高温: 窓の日射、冷気の偏り、壁や窓の残り熱、寝床の熱
- 高温×多湿: 冷房の設定温度を保った除湿
- 多湿: 外気を入れるか閉めて除湿するか、湿気の発生場所、寝具下の通気
- 乾燥: 乾いた風の通り道、過ごす場所の局所湿度、寝床の風と湿度
- 夏の冷房: 首肩へ当たる冷気、足元へたまる冷気
- 冬の冷え: 窓、床、隙間風、寝床
- 温度差: リビングと脱衣所・寝室の差

5〜9月はwarm、11〜3月はcoldとして暦を優先する。春秋だけ、その日のheat/coldを補助判定に使う。これにより、冬の気温上昇で冷房ケア、夏の気温低下で暖房ケアを出さない。

## ショップ接続

身体操作そのものへ商品を割り当てない。主提案がbodyでも、同日の天気に適合するenvironment候補があれば、その`shop_context`から暮らす商品を検索する。環境候補がない気圧だけの日などは、暮らすのショップ導線を表示しない。

部屋間の温度差は`temperature_transition`として、複数地点を見比べられる温湿度計へ接続する。

## UI

- 主提案から直接始める
- 別案がある時だけ`ほかの一手`を表示
- `しっくりこない時`、`trap`、`reset`のグレー欄は表示しない
- 体感欄はbodyなら`ラクになった目安`、environmentなら`合っている目安`
