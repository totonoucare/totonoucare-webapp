# v7.79.4 参考体質デモとサインの日次ローテーション

## 目的

未ログイン予報の計算前提を利用者へ正確に伝え、似た天気が続く日でも「出やすいサイン」が毎日まったく同じ文章になり続ける単調さを抑える。

## 未ログイン予報

未ログイン予報は、体質チェック結果を持たないため、次の参考体質を置いて試算する。

- 反応方向: アクセル／ブレーキの中間
- 余力: 標準
- 天気との親和性: 各方向を中間値で評価

公開APIは、この前提を`reference_profile`として返す。画面では`参考体質で見る体調予報デモ`と表示し、個人の診断結果ではないことを説明する。

## 出やすいサイン

ログイン後の予報では、3件を次の役割に分ける。

1. 主な天気現象から想定する身体反応
2. 選択中の不調から感じ取りやすい観察サイン
3. 選択中の不調から感じ取りやすい別の観察サイン

1件目は同じ天気前提なら固定する。2・3件目は、対象日と不調キーから決定的に候補を選ぶ。

このため、

- 同じ日の再読み込みでは同じ文章になる
- 翌日は候補の並びが変わり得る
- 予報を開くたびにランダムに文章が変わることはない
- 選択していない胃腸・気分など、別領域の不調を勝手に前提へ加えない

## 変更しないもの

- 体調ゆらぎ度
- 天気ストレスの計算
- 体質親和性
- 余力補正
- 対策ケアの選定
- DBスキーマ
- 環境変数
