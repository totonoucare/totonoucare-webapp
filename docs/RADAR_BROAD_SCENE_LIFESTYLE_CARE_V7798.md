# v7.79.8 暮らすケアの基本動作・具体策二段階選定

## 目的

v7.79.7には22件の具体的な身体操作がありましたが、候補選定でも各操作を直接競わせていました。

そのため、同じ天気と不調が続くと、モップ、洗濯かご、画面作業など少数の細かな場面だけが交互に出やすい構造でした。

v7.79.8では、次の順で選びます。

1. その日の不調・天気・体質に合う基本動作を選ぶ
2. 選ばれた基本動作の中から、具体的な操作を選ぶ

文章量や画面構造は増やしません。

## 九つの基本動作

| キー | 表示名 | 場面文 |
|---|---|---|
| `hold_carry` | 持つ・運ぶ | 物を持つ・運ぶ時は |
| `push_pull_turn` | 押す・引く・回す | 物を押す・引く・回す時は |
| `reach_take` | 手を伸ばす・物を取る | 手を伸ばして物を取る時は |
| `bend_height` | かがむ・高さを変える | かがむ・高さを変える時は |
| `sit_rise` | 立つ・座る・起き上がる | 立つ・座る・起き上がる時は |
| `walk_step` | 歩く・段差を移動する | 歩く・段差を移動する時は |
| `screen_handwork` | 手作業・画面操作 | 手作業や画面操作が続く時は |
| `hold_posture` | 同じ姿勢で待つ・作業する | 同じ姿勢で待つ・作業する時は |
| `lie_turn` | 横になる・寝返る | 横になる・寝返る時は |

モップ、スマホ、洗濯かご、扉などは基本動作ではありません。各基本動作の中で選ぶ具体操作の例です。

## 選定方法

### 第一段階: 基本動作

候補スコアには既存どおり、次を使います。

- 選択中の不調
- 主・副の天気ストレス
- ケア方針
- アクセル／ブレーキ
- 余力
- 動作の強さと安全除外

選択中の不調に合う基本動作が十分にある場合は、その中だけで場面候補を作ります。

近いスコアの場面を最大6件まで保持します。4件以上ある場合は最低4件をローテーション対象に残し、日替わりのためだけに無関係な不調へ広げません。

### 第二段階: 具体操作

選ばれた基本動作に属する具体操作を日付で決定的に選びます。

基本動作が一巡して再登場した時は、複数の具体策がある場面なら別の操作へ進みます。

同一日・同一条件の再読込では、同じ結果を返します。

## 連続日の条件

- 隣接日に同じ`scene_family`を出さない
- 関連場面が4種類以上ある不調では、同条件の7日間に4種類以上を出す
- 主提案と代替案は、異なる基本動作から返す
- 複数の具体策がある基本動作は、再登場時に同じaction idへ固定しない

睡眠、消化、めまいなど、安全かつ不調に合う基本動作が3種類の時は、無関係な4種類目を足しません。

## 維持する境界

- v7.79.7の簡潔な対策ケア表示を維持する
- A/B比較、追加チェック、比較前後の入力は追加しない
- 内部の身体OSとユーザー表示文の分離を維持する
- めまい時の歩行・階段・深い拾い動作を除外する
- 商品名や検索語を対策ケアへ出さない
- 既存`tension-*` action idを維持し、ショップ検索へ接続する

## 変更しないもの

- 体調ゆらぎ度
- 天気ストレス
- 体質親和性
- 余力補正
- 出やすいサイン
- 予報保存形式
- DB / SQL
- 環境変数
