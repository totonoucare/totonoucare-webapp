# v7.79.7 正中張力OSによる暮らすケア

## 変更の目的

旧案の`暮らす`は、首や腰だけで動かさない、荷物を体へ近づける、足へ仕事を分けるなど、安全ではあるものの一般的な身体操作に留まっていました。

この版では、生活の基本動作を先に分類し、`docs/BODY_USE_TENSION_CONTINUITY_OS.md`を内部の思考資材として使用します。身体OSを説明しやすい場面だけへ候補を狭めません。

内部の`BODY_MECHANICS_INTERNAL_CANDIDATES`と、画面用の`PUBLIC_ACTION_COPY_BY_ID`は明確に分離します。

## 表示構造

主提案は次を一組で表示します。

- 場面: 条件付きで、利用者の実際の習慣を決めつけない
- 操作: その場で一度試せる身体操作
- 理由: どの部位だけへ負担を集めないか
- できた目安: 身体や道具の位置を目で確認できる条件
- うまくいかない時: 崩れた位置と、具体的なやり直し方

商品名や検索語は表示しません。

## 九つの基本動作

- 持つ・運ぶ
- 押す・引く・向きを変える
- 画面・手作業
- 立つ・待つ
- 歩く・段差
- 座る・立ち上がる
- 手を伸ばす・かがむ
- 横になる・寝返る
- 見る方向を変える

場面を細分化しすぎず、各候補の操作だけを具体化します。

## 表示語の境界

画面へ出さない語:

- 橈骨、母指、正中、張力、起始側
- 伸張、荷重、重心線、拮抗
- 足は下・頭は上、軸を通す、手の空間など、判定できない感覚語

画面へ出す情報:

- 手、足、ひじ、画面、取っ手などの位置
- 一歩近づく、両手で支える、膝を曲げるなどの動き
- 肩の高さ、手首の角度、足裏の接地などの確認条件
- 崩れた時に、何をどこへ戻すか

## 候補選定

候補スコアには次を使用します。

1. 選択中の不調
2. 主な天気ストレス
3. 副次的な天気ストレス
4. その日のケア方針
5. アクセル／ブレーキ
6. 余力
7. 動作負荷

主な天気ストレスと不調の双方に合う候補が2件以上ある時は、その群を優先します。これにより、日替わりのためだけに天気と無関係な動作が混ざることを抑えます。

同一日・同条件の再読込では固定します。連続日は上位候補の`scene_family`を決定的に回し、同じ場面が隣接日で続かないようにします。

## 安全条件

- `dizziness`では歩行、階段、深い拾い動作を除外
- 壁押し・片足立ちなど、開発者が思考資材として示した練習を一般候補へ直接採用しない
- 不安定、痛み、強い負担が出る時は、通常動作へ戻す文を各候補へ持たせる

## ショップ

予報からショップへ渡すのは`liveAction / liveRole / liveScene`だけです。

ショップAPIは登録済み`tension-*` action idだけを検索語へ変換し、`body_mechanics`由来の`暮らす`候補として加点します。商品は既存の`暮らす・食べる・ほぐす`セットへ組み込みます。

## 変更しないもの

- 天気ストレス
- 体質親和性
- 余力補正
- 出やすいサイン
- 体質チェック
- DB
- 環境変数
