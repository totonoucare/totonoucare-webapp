# 暮らすケアの場面と道具

候補文・確かめることはv62の17件を継承。体質・天気・不調との適合に加え、下記の場面で候補を絞る。道具なし1件・道具あり1件を基本とし、適合する候補がなければ件数を埋めない。

| 条件・場面 | 選択する場面 | 道具 | 表示 |
|---|---|---|---|
| 今夜、冷えが気になる時 | 寝る前 | 浴槽・足湯の容器 | 通常候補 |
| 机で作業する時 | 机・椅子 | 机 | 通常候補 |
| スマホや本を見る時 | スマホ・読書 | 安定した台 | 通常候補 |
| 椅子に座ると足が床に届かない時 | 机・椅子 | 安定した足台 | 条件付きで折りたたむ |
| 眠る前に光がまぶしく感じる時 | 日常・休む時・寝る前 | 追加の道具なし | 通常候補 |
| 背もたれのある椅子に座る時 | 机・椅子 | タオル・背もたれ | 通常候補 |
| あお向けで脚を休める時 | 日常・休む時・寝る前 | 薄いクッション | 通常候補 |
| 横向きで休む時 | 日常・休む時・寝る前 | 枕またはタオル | 通常候補 |
| 横の画面を見るたびに頭を動かしている時 | 机・椅子 | 画面の配置 | 条件付きで折りたたむ |
| テレビ・音楽・通知音が重なっている時 | 日常・休む時・寝る前 | 追加の道具なし | 通常候補 |
| 軽いコップなどを持つ時 | 物を持つ時 | 追加の道具なし | 通常候補 |
| 荷物を両手で持つ時 | 物を持つ時 | 追加の道具なし | 通常候補 |
| スマホを操作する時 | スマホ・読書 | 追加の道具なし | 通常候補 |
| 立っている時 | 日常・休む時 | 追加の道具なし | 通常候補 |
