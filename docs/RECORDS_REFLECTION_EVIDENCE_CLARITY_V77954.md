# v7.79.54 振り返りの比較記録を読みやすくする

## 問題

AIの`evidence`は55文字以内の文字列です。比較条件、ケアの有無、各群の日数、実感の内訳を一文へ入れると、次のように係り受けが崩れます。

> 湿気・安定の近い条件では、ケアあり2日が穏やか1日・軽い不調1日、ケアなし1日は穏やかでした。

意図している集計は正しくても、母数と結果の対応がすぐには分かりません。

## 表示

比較値はAI文から読み取らず、`summary.matched_forecast_comparisons`を正本として次の順に表示します。

1. 比べた条件と合計日数
2. ケアあり群の日数と実感内訳
3. ケアなし群の日数と実感内訳
4. AIが個別に確認した日付の記録

例:

- 比べた条件: 湿気が主・体調警戒度20〜29（安定）: 3日
- ケアあり（2日）: 穏やか 1日／軽い不調 1日
- ケアなし（1日）: 穏やか 1日

## 選択と互換性

- AIの短文に天気ストレス名とモード名があれば、対応する比較グループを優先します。
- ケアあり・なしの両群が存在しない時は比較カードを出さず、AIの個別記録だけを表示します。
- 保存済みAI分析の圧縮文も表示時に置き換わるため、分析の再生成は不要です。
- 集計値、AI prompt/schema、DBは変更しません。
