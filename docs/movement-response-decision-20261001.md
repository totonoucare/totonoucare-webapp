# movement_response 設計判断メモ

決定日：2026-10-01（日本時間）
対象：未病レーダー v7.79.89 の体質チェック
状態：改修検討停止・現行公開版を基準モデルとして維持

## 決定

movement_responseに関する係数・分母・reaction軸の変更を保留する。新ロジックの実装、既存データの更新、バックフィルを実施しない。回答保存と現行の設問表示条件を維持する。以前作成したmovement-impact-kitは検討履歴として扱い、改修計画として続行しない。今回、候補式による個票比較も実行していない。

停止対象：

- 気虚・気滞・痰湿へのmovement係数の変更・削除
- movement非表示時の分母変更
- varies時の分母変更
- reaction軸へのmovement寄与の変更・削除

## 判断を変更した理由

当初、movementの直接加点、非該当回答でも残る固定分母、reaction軸にも作用する構造を見直し候補としていた。利用者から提示された追加検討を踏まえ、以下を現行維持の設計仮説として記録する。

1. movementは症状量に加え、重さ・疲れが生じる機序を見分ける補助質問として解釈できる。easierは気滞や気滞を伴う痰湿、more_tiredは気虚・推動力不足、no_changeは既存の重さや食後負担と合わせた痰湿の評価を補助する可能性がある。variesでは機序の方向を確定せず積極的加点を控える。
2. 固定分母による減衰は、弱い境界所見へのラベル表示を抑える役割を持つ可能性がある。例えばqi_obstruction=sometimes、stress_variability=rare、movement加点なしでは、現行32.6点に対してmovement除外式は37.5点となり、35点の候補閾値を跨ぐ。ただし35点以上でもsub_labelsは上位2件の選択なので、表示が必ず追加されるとは限らない。
3. 回答群間では症状量や複数所見の程度も異なる。movement成分を除いた群平均だけから、鑑別補助としての加点の要否や係数の適否を決めることはできない。
4. 今回の検討では、変更を支持する根拠が十分に揃っていないという判断に至った。現行ロジックに設計上の意味がある可能性を尊重し、追加の実利用データを蓄積する。

これらは設計上の解釈・検証仮説として保持する。係数0.30・0.35等の最適性、診断精度、固定分母の確信度校正は未検証。no_changeによる他病機の除外も確定的に解釈しない。「明確な系統的誤判定は確認できていない」は利用者から共有された今回の判断であり、このメモ作成時に独立した臨床評価や全例検証を追加実施したものではない。

## 再検討の条件

次のいずれかを確認した時点で、改めて検討する。

1. 同種の「体質判定が合わない」という利用者の違和感が繰り返し得られる。
2. 特定の回答パターンで系統的な誤判定を示す実データが得られる。
3. 現行・候補式の全症例比較で、主要ラベル・動物タイプ・境界例の明確な改善を示せる。

改善は変更件数の多寡に加え、本人の評価や独立した評価基準との整合で判断する。再検討時も、その時点の明示的な依頼に基づいて進める。

## 添付データの位置づけ

参考資料：貼り付けられたテキスト（1 点）.txt

CSV形式でdiagnosis_id、user_hash、created_at、registered_user、model_revision、movement_response、answers、computedを含むことを確認した。今回は資料受領と設計判断の記録に留め、候補ロジックの比較集計は行わない。

今後集計する場合、イベント件数と人数を区別する。数秒差の同一・類似回答は重複候補として扱い、除外条件を明示する。ユーザー識別情報がない記録は同一人物と断定せず、人単位の集計の限界を記載する。model_revisionも整理する。

## 別件の保存整合性

体のラインPATCHで、過去診断の回答・computedが現在プロフィールに反映され、タイプ等の保存列が残る問題は、先のソース確認と合成データによる再現で確認済み。movement係数の妥当性とは分けた保留事項として残す。今回の方針を受けて、この件も自動的に修正へ進めない。実ユーザーにおける発生人数は未確認。

## 実施内容

この設計メモのみを新規作成。アプリのソース、DB、既存の回答・診断結果は変更していない。
