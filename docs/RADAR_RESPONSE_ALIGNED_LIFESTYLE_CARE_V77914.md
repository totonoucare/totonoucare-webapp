# v7.79.14 反応予測と暮らすケアの一貫化

## 目的

暮らすケアを「暑いから遮熱」「湿気が多いから除湿」という天気対策から切り離し、同じ天気でも本人の反応方向、余力、気血水、選択中の不調によって別の一手が出る設計へ改める。

身体の使い方は、局所筋で頑張らず、接触点や荷重を残しながら身体の中心側を動かす独自の身体操作OSを一般生活語へ翻訳する。環境調整は、人間工学と回復環境からその身体反応を受け止める。

## 判定の流れ

1. 天気ストレスを身体を揺さぶるきっかけとして受け取る。
2. アクセル／ブレーキ／balanced、余力、気血水、連続体質値、選択中の不調を重ねる。
3. `daily_response_profile_v1`として、反応方向、主・副の7方針、対象不調、根拠を保持する。
4. 同じ反応プロファイルを、予報方針、暮らすケア、ショップ接続で使う。
5. 猛暑・厳寒などの一般的な安全対策は、従来どおり予報側の注意表示へ残す。

## 出やすいサインとの整合

「出やすいサイン」は、天気全体、天気と不調、体質反応と不調の三層で観察点を示す。暮らすケアはその文章を再生成せず、同じ入力軸を共通の反応プロファイルへ変換する。

- 明示された反応方向を優先し、`balanced`をコア体質のアクセル／ブレーキで上書きしない。
- 選択中の不調を主アンカーから落とさない。
- 気血水と余力を7方針および候補順位へ反映する。
- サインで胃腸を見ている日に、首肩専用の身体操作を件数合わせで流用しない。
- サインは「起こり得る観察」、ケアは「その反応を生活で増幅させにくい一手」と役割を分ける。

画面ではサインと同じ内容をケア欄で長く繰り返さず、ケアカードの外に`天気 / 体質 / 不調`の根拠ピルを置く。

## 7つの方針

| 方針 | 主に扱う反応 |
| --- | --- |
| しずめる | 熱・高ぶり |
| ゆるめる | 力み・こわばり |
| めぐらせる | 巡りの滞り |
| ながす | 重だるさ・むくみ |
| うるおす | 乾き・消耗 |
| ぬくめる | 冷え・縮こまり |
| ささえる | 疲れ・余力不足 |

天気単独の点は小さくし、反応方向、気血水、余力、連続体質値、不調を合わせて主・副方針を選ぶ。気圧の物理方向と身体の反応方向は引き続き分離する。

## 暮らすケアの選定

候補は`身体の使い方`と`環境調整`の二系統だけを使う。

評価軸は次のとおり。

- 選択中の不調: 最大40
- 予想される反応と7方針: 主方針22、副方針11。主・副の両方へ合う場合は加点
- 体質、余力、気血水: 最大20
- 天気: 最大12
- 実行時間帯: 5または10
- 実行しやすさ: 余力に応じて評価。余力が小さい時は低負荷の環境調整を優先

主提案は必ず選択中の不調へ合う候補から選ぶ。第二案も同じ不調へ合うことを必須とし、適合度が近ければ主提案と異なる系統を優先する。最低適合度に届かない候補や、別の不調用候補は件数合わせに使わない。

同じ条件・同じ日は同じ結果を返す。今日と明日は、適合度が近い関連候補だけを日付で巡回させ、モード別の追加オフセットは使わない。

## 身体の使い方

内部OSは次の原則を維持する。

- 局所筋だけで荷重を抱えない。
- 末端や接触点を急に引き込まず、身体側を連動させる。
- 足元、呼吸、体幹、腕を分断しない。
- 正しい形を押しつけず、同じ動作が軽くなるかで確かめる。

画面文では専門語を使わず、実際に存在する生活場面、具体動作、理由、体感の目安へ翻訳する。スマホ操作は「反対の手でも下から支える」「親指だけでなく、ひじから手全体の位置も変える」とした。

めまい、余力小などの安全除外は維持する。片足立ちのような練習負荷が高い候補は、めまいと余力小では選ばない。

## 環境調整

環境調整は天気への一般対策ではなく、予想される身体反応を人間工学と回復環境で受け止める。

主な候補群:

- 腕を預ける支持面
- 画面・読み物の高さと距離
- 背中・腰の支持
- 足元、座面、脚の支持
- 作業高と腹部を折りたたみにくい配置
- 寝返り、横向き、膝下を支える寝具
- 視線の正面配置、遮光、音刺激の調整

一般的な冷房・除湿・換気だけで個別ケアを決めない。安全上必要な暑熱・寒冷注意は、暮らすケアとは別の注意表示で扱う。

## 画面

- 種別名を`環境調整`へ統一した。
- 根拠を`天気 / 体質 / 不調`のピルとしてカード外へ表示した。
- 根拠文を場面と提案の間へ差し込まない。
- 主提案は`①`、第二案は`②`の同格カードにした。
- `ほかの一手・しっくりこない時`とリセット文の表示を廃止した。
- 身体の使い方は`ラクになった目安`、環境調整は`合っている目安`を表示する。

## ショップ

> v7.79.15で商品導線の境界を更新した。身体操作IDを商品検索へ変換せず、同じ反応に合う独立した環境調整コンテキストだけをショップへ渡す。現行仕様は`RADAR_LIFESTYLE_PRODUCT_BOUNDARY_V77915.md`を参照。

商品名は予報カードへ出さない。カードでは「腕の重さを預ける」などの生活ケアを示し、ショップではその機能を助ける商品役割へ変換する。

身体の使い方が主提案でも、主・第二案からショップ接続可能なケアを探す。身体操作そのものの商品適性は候補スコアへ入れず、予想される崩れ方を補助できる用品へ接続する。

追加した主な役割は、背中・腰支持、脚支持、横向き寝具、正面配置、音刺激低減。楽天検索のaction idと役割推定も同時に更新した。

## 検証

- 暮らすケア、予報、気圧反応、7方針に関する回帰テスト98件を通過。
- `7天気 × 9不調`で、主提案から選択中の不調が落ちないことを確認。
- 胃腸とめまいへ、無関係な身体操作を流用しないことを確認。
- 明示的`balanced`を上書きしないことを確認。
- 今日と明日の主提案重複率が25%以下になることを固定テスト化。
- 変更前フルソースでも失敗していた5つの既存テストファイル以外に、新しい全体回帰失敗がないことを比較確認。
