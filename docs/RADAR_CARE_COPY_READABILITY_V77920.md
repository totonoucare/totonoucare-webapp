# v7.79.20 ケア文言の自然化・可読性・暮らす導入文

## 目的

食性を選定根拠として使いながら、画面上で`食養生`を一つの学術体系のように見せない。また、食べる・暮らすの主要情報をスマートフォンで読みやすくし、暮らすタブでも「なぜ今日この一手なのか」を一手より先に理解できるようにする。

## 表示文言

- 食事・飲み物の第一理由ラベル: `食養生` → `体調との相性`
- 第一理由本文: `食養生では、トマトは…` → `トマトは、こもった熱を冷ましながら水分を補う方向の食材です。`
- 食べるタブ種別バッジ: `食養生` → `食事ケア`
- 第二理由は料理で`栄養面`、飲み物で`成分・飲み方`を維持する

これは食性を廃止する変更ではない。内部の寒熱、五味、食材タグ、体質、不調、天気による選定を保ち、ユーザー表示だけを役割が伝わる生活語へ直す。

## 暮らす導入文

`buildLifestyleForecastInsight`は、食べるタブと同じ予報コンテキストから次の四要素を組み立てる。

1. 主・副の天気トリガー
2. アクセル寄り／ブレーキ寄りの反応方向
3. 選択中の不調
4. 選ばれた主提案が身体の使い方か環境調整か

表示例:

> 今日は高温と気圧変化の予報にアクセル寄りの反応が重なり、首肩のつらさが出やすい見込みです。暮らしでは、身体の使い方を少し変え、負担が一か所へ集まりにくくします。

環境調整が主提案なら、後半を次のように変える。

> 暮らしでは、道具や配置を整え、負担が一か所へ集まりにくくします。

明日表示では`明日は`と`今夜からの暮らしでは`を使い、明日への先回りであることを明示する。

## 文字サイズ

- 食べるケアの導入: 15px
- 取り入れたい食材: 16px
- 料理案・選定理由: 13px
- 暮らすケアの導入: 15px
- 暮らす一手: 16px
- 暮らす理由・体感目安: 14px
- 方針要約: 15px
- 小見出し・根拠ピル: 原則12px
- `やってみた`等の操作ボタン: 12〜13px

## 変更していない範囲

- 7つの方針と共通反応プロファイル
- 食事・飲み物の候補選定とローテーション
- 身体操作OSと環境調整候補の採点
- 出やすいサインと予報スコア
- 身体操作と商品導線の境界
- ショップのマクロな継続ケア軸
- DB、API、環境変数

## 回帰条件

- ユーザー表示に`食養生では`を出さない
- 食事・飲み物の第一理由ラベルは`体調との相性`
- 暮らす導入文に天気、反応方向、不調、主提案レーンを含める
- today/tomorrowの時間軸を取り違えない
- 食べる・暮らすの主要本文を15px未満へ戻さない
