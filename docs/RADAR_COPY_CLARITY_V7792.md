# v7.79.2 予報文の条件整合と比喩表現

更新日: 2026-07-27

## 修正の目的

予報ページの「出やすいサイン」で、選択した不調とは別の身体条件を文章側が勝手に補っていました。

例:

- 選択中の不調: 気分の浮き沈み
- 表示: `胃腸が重い日は、気分にも湿気がたまりやすい`

この文章は、気分の不調を選んだことだけを根拠に、胃腸の重さと湿気を追加しています。気分と胃腸の関連そのものを否定する修正ではなく、入力にも計算結果にもない条件を断定しないための修正です。

## 原因

出やすいサインは次の構成でした。

1. 主な天気現象から選ぶサイン
2. 選択中の不調ごとに固定されたサイン
3. 選択中の不調ごとに固定されたサイン

`mood`の固定文に胃腸・湿気の表現が含まれていたため、実際の天気ストレスや胃腸症状に関係なく表示されていました。

## 新しい文章契約

### 出やすいサイン

- 1件目: 主な天気現象から想定されるサイン
- 2・3件目: 選択中の不調そのものから本人が気づけるサイン
- 別の身体領域を条件にしない
- ケア方法や行動条件は「対策ケア」で扱い、サインへ混ぜない

`気分の浮き沈み`では、胃腸や湿気を補わず、次のような観察可能な表現を使います。

- 気持ちの切り替えに時間がかかりやすい
- 疲れているのに、焦りや落ち着かなさが先に出やすい
- いつもなら流せる小さな刺激が気になりやすい

### 比喩表現

東洋医学の世界観を専門知識なしでイメージできる比喩は残します。

残す例:

- 熱が上にこもる
- 湿った上着をまとったように重い
- 気持ちや体が前のめりになる

修正する例:

- 気分に湿気がたまる
- 体の入口を閉める
- 力みの出口をつくる
- 頭に仕事を集める
- 胃腸を置き去りにする

判断基準は、読んだ人が身体感覚を具体的に想像できるか、文章が入力にない因果を追加していないかです。

## 修正範囲

- 予報本文と出やすいサイン
- 暮らす
- 食べる
- ほぐす・ツボ説明
- 関連するフォールバック文

## 変更していないもの

- 体調ゆらぎ度
- V2予報スコア
- 体質・気血水・余力の補正
- 天気ストレスの算出と表示
- 対策ケアの選定ロジック
- DBスキーマ、migration、環境変数
- Stripe決済・契約判定

## 回帰確認

- 暑熱ストレスと気分の不調が同時にある場合、胃腸・湿気を混入させない
- 安定日の気分サインにも胃腸・湿気を混入させない
- 気分以外の不調でも、本人が回答していない別症状を条件語にしない
- 湿気と気分が同時に関係する場合も、身体の重さと気分の切り替えを分けて説明する
- 監査対象の不明瞭な比喩がユーザー向け文言へ戻らない
