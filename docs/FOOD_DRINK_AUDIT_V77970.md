# v7.79.70 食べるタブの横断点検

今回の範囲は、飲み物14種類の選定条件・表示理由・補足、食材81種類に使う理由生成、控えめ候補の全分岐、保存済み予報から表示する経路です。体質チェック結果文と食材ローテーションはv69の改修を継承しています。

## 飲み物14種類の判断

| 飲み物 | 点検結果・今回の扱い |
|---|---|
| 水 | 水分補給の基本。気圧やむくみを理由に水そのものを控える条件は置かない。症状改善の効果は付けず、飲みやすさを説明。 |
| 白湯 | 食性は平、温かさは飲用温度で評価。冷えへの適合を温度の理由で説明。生薬の温性と区別する。 |
| 麦茶 | 涼の整理を維持。暑さがある場合だけ暑さへの備えと説明。冷えと衝突するときは候補から外し、温かく飲めば食性の不一致が消える扱いを避ける。 |
| ほうじ茶 | 焙煎香を取り入れる選択肢。香味からの理気方向は内部で推論として区別。温性・健脾の一律扱い、カフェインが常に少ないという表現を修正。 |
| 緑茶 | 涼・清熱と、苦味・香り・カフェインを整理。気圧変化や頭痛だけで冷ます理由を出さない。冷えとの衝突、眠りを主訴にした場合に配慮。 |
| コーヒー | 苦味・香り・目覚めの一杯という特徴を保持。香味を食養生へ応用する部分は推論として区別。気圧変化・頭痛だけの特別加点を撤去し、選ばれた文脈と説明を一致させる。 |
| デカフェコーヒー | 苦味・香りを楽しみつつカフェインを減らす候補。微量のカフェインがある製品を含むため、含有ゼロと書かない。利水や鎮静の効果は付けない。 |
| ルイボスティー | 風味のあるノンカフェインの水分補給。乾燥時やカフェインを控えたい場合の特徴を説明。眠りの改善や鎮静・滋陰を確立した作用として加点しない。 |
| はとむぎ茶 | 利水・健脾に着目する食養生を選定へ反映。体質、むくみ、湿気、暑さのどの条件に合ったかで表示を変える。湿気も痰湿もない場合に重だるさを前提にしない。 |
| とうもろこし茶 | 穀物由来の消化・吸収を支える食養生を推論として反映。実のお茶として扱い、ひげ茶の利水属性を一括転用しない。湿気と消化・吸収の説明を短くつなぐ。 |
| 小豆茶 | 水分の偏りに着目する食養生を推論として反映。むくみの入力、痰湿の体質、湿気の予報を区別する。ほかの理由で選ばれた場合は小豆の風味を説明。 |
| 黒豆茶 | 体を養う方向を推論として反映。疲労・消耗傾向に合う場合はその理由を説明し、香りや水分補給で選ばれた場合はその理由を優先。腰の痛みを直接改善する表現は使わない。 |
| 生姜湯 | 温を維持。冷えがある場合の候補として説明し、暑さとの衝突時は候補から外す。気圧上昇だけを理由に生姜を避ける旧条件は撤去。冷えを確認できない場合の文は条件付きにする。 |
| 葛湯 | 温かいでんぷん飲料・任意の少量の補食。小腹が空いた場合という条件を明記。葛根という生薬の食性や作用をそのまま移さない。 |

タグ、向いている条件、注意条件を一つの現行カタログへ集約しました。以前はタグを変更した後も旧条件の加点が残る構造でした。食養生上の推論タグは内部で識別し、通常タグより小さい設計上の加点にしています。数値は選定のための設計値です。効能の実測値や確率を表すものではありません。

## 頭痛以外で見つかった説明の問題

| 見つかった問題 | 修正 |
|---|---|
| 血虚や乾燥から選んだ食材に、未申告の口・喉の乾き、便の硬さなどを付ける | 食養生の「養う・うるおす」という方向を説明し、部位別の症状を決めつけない。 |
| 気滞やゆるめる方針から胃腸の話へ急に移る | 食養生では緊張へのケアに胃腸を整える食材も組み合わせる、というつながりを2文で説明。 |
| 気虚や疲れから健脾を選び、胃腸の不調を前提にする | 消化・吸収を支えることを元気を補うケアにつなげて説明。 |
| 胃腸の主訴だけで冷たいものを控える提案になる | 脂っこいもの・一度に食べる量を控える候補を独立させる。寒熱は別条件で扱う。 |
| 痰湿があると、明日の暑さや乾燥より先にいつも同じ注意が選ばれる | 眠り・胃腸・むくみの主訴に対応する条件を確認し、その後は対象日の主・副気象、体質の順で選ぶ。 |
| 津液不足や熱傾向を、当日の乾燥・暑さとして表現する | 気象由来・体質由来・ケア方針由来の理由を分ける。 |
| 今日タブで「明日に備え、今夜は」と出る | 今日／明日の表示モードを注意文にも渡す。 |
| 保存済みの飲み物を、主訴や予報が変わっても引き継ぐ | 表示時に現在の主訴と選択日の予報から飲み物を再選定。記録済みの実飲スナップショットは編集しない。 |
| 明日朝の飲み物を、夜の飲み物として一律にカフェイン除外する | 明日朝の候補として選定。眠りが主訴ならカフェイン入りを除外し、朝食案は実飲として記録できない契約を維持。 |

## 確認方法と範囲

- 自動回帰テスト：57件合格。食材・飲み物の表示、食べた／飲んだ記録、保存時の処理、AIへ渡す実施内容、体質ラベル、寒熱、日付・主訴の切替を確認。
- 組合せ点検：`scripts/audit-food-context-v77970.mjs`。体質25パターン（6分類の単独・2分類組合せ、分類なし、冷え・熱・混在）、主訴9種類と未選択、気象8種類と副気象、今日／明日の28,500条件。
- 食材・飲み物の表示理由と注意文に、入力していない主訴、気象由来の取り違え、日付の不一致、長文化、飲み物の寒熱衝突がないかを、定義したルールで確認。
- 全14種類が少なくとも一つの条件で表示上位2候補に入ることを確認。出現数は人工的な組合せの集計であり、実際の利用者に対する出現率ではありません。
- 全14種類の代表文、9主訴に対応する分岐、食材の機能別説明、注意文の全分岐をコードと出力でレビュー。
- 28,500条件を一文ずつ手作業で読む代わりに、自動検査と代表・境界条件の読解を組み合わせています。食養生タグの医学的有効性の実証は今回の検証範囲外です。
- Next.jsの本番ビルドとログイン後の実画面確認は未実施。UI構造・スタイルの変更はありません。
